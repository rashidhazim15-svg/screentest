# فحص مجاني لصلاحية تسجيل الشاشة على iPhone (iOS 27)

الهدف: نتأكد أن الهوية المجانية (Apple ID العادي) تسمح بصلاحية «تسجيل الشاشة» قبل بناء التطبيق الكامل. بدون أي دفع.

## ما الذي أعددته لك
- `project.yml` — إعدادات المشروع (يتضمن `UIBackgroundModes: screen-capture` ووصف إذن الشاشة).
- `Sources/ScreenTestApp.swift` — شاشة فيها زر «فحص» يفتح منتقي آبل ويعرض النتيجة أو الخطأ.
- `.github/workflows/build.yml` — يبني IPA على GitHub Actions مجاناً (بدون ماك عندك).

## خطواتك (مرة واحدة)
1. افتح https://github.com/new وسجّل الدخول بحساب GitHub.
2. اسم المستودع مثلاً `screentest` واجعله **Public** (مهم لكي تكون Actions مجانية) ثم اضغط Create repository.
3. في صفحة المستودع اضغط **uploading an existing file** واسحب كل ملفات مجلد `ios-test` (بما فيها المجلد `.github` مخفي — تأكد أنه انرفع).
4. اضغط **Commit changes**.
5. افتح تبويب **Actions** → على اليسار اختار **Build ScreenTest IPA (free)** → اضغط **Run workflow** ثم زر الأخضر **Run workflow**.
6. انتظر دقيقتين.. خلاص يطلع **ScreenTest-ipa** → اضغته وينزّل ملف `ScreenTest.ipa`.

## التثبيت على آيفونك (مجاني)
1. نزّل **Sideloadly** من https://sideloadly.io على ويندوز وثبّته.
2. وصّل آيفونك بالكابل (أو نفس Wi-Fi).
3. في Sideloadly: اسحب `ScreenTest.ipa`، أدخل إيميل Apple، واضغط **Start**.
4. في المرة الأولى بيطلب كلمة مرور مخصصة للتطبيقات (App-specific password) — اتبع التعليمات (تقدر تنشئها من إعدادات Apple ID).
5. على الآيفون: الإعدادات ← الخصوصية والأمان ← **Developer Mode** ← فعّله وأعد تشغيل الجهاز.
6. افتح التطبيق «ScreenTest» من الشاشة الرئيسية واضغط **فحص**.

## ماذا تكتب لي؟
انسخ اللي ظهر في التطبيق (مثلاً: `شاشات: 1 | تطبيقات: 40 | تم فتح منتقي آبل` أو `خطأ: ...`) وأرسله لي.
- إذا ظهر «تم استلام إذن المصدر ✓» → صلاحية مجانية شغالة، ونبدأ التطبيق الكامل.
- إذا ظهر خطأ يذكر entitlement أو background mode → بنحوّل لبديل مجاني فوراً بدل ما نضيع وقت.

> ملاحظة: التوقيع المجاني ينتهي بعد ٧ أيام. للاختبار يكفي. التحديث = إعادة فتح Sideloadly وضغط Start مرة ثانية.
